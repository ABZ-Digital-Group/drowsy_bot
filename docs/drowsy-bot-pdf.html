Drowsy Bot • PDF Overview

Stage automation, invite moderation, and OBS-ready overlays in one Discord bot.

Drowsy Bot is a Node.js and discord.js bot built around hosted music events. It manages stage queues, tracks live performers, supports sponsor overlays, and provides moderation utilities for invite control inside a Discord server.

Core Value

  • Runs hosted stage or open-mic events through mirrored queue control panels.
  • Feeds OBS with now-singing text and browser overlays for remote hosting setups.
  • Supports ad uploads, live ad rotation, and post-event stats for staff wrap-up.

Event Flow

  1. Staff joins the target voice channel and runs /start-queue.
  2. The bot posts a control panel and opens the lineup for participants.
  3. Members join the queue, advance to the stage, and end turns with the panel or staff action.
  4. Radio fallback returns when no singer is active.
  5. At /stop-queue, the session returns performers, audience, songs sung, and peak attendance.

Operational Commands

/start-queueLaunch the active stage session in the current text channel.
/queuePost the current lineup and active stage state.
/open-queueAllow new users to enter the current lineup.
/close-queuePause new joins while keeping the active session running.
/nextAdvance directly to the next performer.
/radioToggle the background intermission track.
/stop-queueEnd the event and return the post-event stats block.
/eventsPublish links for live and upcoming Discord scheduled events.

Runtime Requirements

  • Node.js 20 or newer.
  • A Discord application and bot user.
  • Guild permissions for stage administration, messaging, and channel management.
  • Optional OBS host access through the configured HTTP endpoint for remote browser overlays.

Data and Outputs

  • Runtime JSON files stored under the data directory.
  • Now-singing text and JSON outputs for OBS scene integration.
  • Uploaded ad images stored locally for on-stream sponsor rotation.
  • Stage sessions kept in memory while active, including live queue metrics.
